# Contributing to Predict-Heart-Attack-using-AI

Thank you for your interest in contributing! 🫀

## How to Contribute

1. **Fork** the repository and clone it locally.
2. Create a **feature branch**: `git checkout -b feature/YourFeature`
3. Make your changes, following the code style guidelines below.
4. Add or update **tests** in the `tests/` directory.
5. Run `pytest tests/ -v` to ensure all tests pass.
6. **Commit** with a clear message: `git commit -m "feat: Add YourFeature"`
7. **Push** and open a **Pull Request** against `main`.

## Code Style

- Follow PEP 8 (max line length 100 chars)
- Use type hints for all function signatures
- Add docstrings to every class and public method
- Keep functions focused and under 50 lines where possible

## Reporting Issues

Use GitHub Issues with the appropriate label:
- `bug` — something is broken
- `enhancement` — new feature or improvement
- `documentation` — docs improvement
- `question` — general question

## Medical Data Guidelines

- Never commit real patient data
- All sample data must be synthetic or publicly licensed
- Follow HIPAA/GDPR principles in any data handling code

Thank you for helping make this project better! ❤️
